## 问题

1. 语音输入按钮当前位于下方状态栏（Composer 底栏）**末尾**，位置不符合使用频率，且**图标偏大**（与同栏其它控件不是一个视觉重量）。
2. 上下文圆环目前也占在下方状态栏里，且**显示百分比**，信息冗余、视觉嘈杂。
3. **新会话（空会话）时上下文圆环不显示**——没有上下文用量就没有环，状态栏在这一态缺少该指示。

## 目标

1. 语音输入按钮移到**「权限选择」之后**（紧邻权限选择控件右侧）。
2. 上下文圆环移到**下方状态栏末尾**（即语音输入原来的位置）。
3. 圆环**不显示百分比**（只保留环形本体）。
4. **新会话为空时也要显示圆环**（0 用量的空环状态），与有用量时的位置、尺寸、样式连续。

## 验收标准

1. 下方状态栏的从左到右顺序为：`… → 权限选择 → 语音输入 → …（其它控件）… → 上下文圆环`，圆环位于整条状态栏的**最后一个**。
2. 语音输入图标**缩小**到与下方状态栏其它图标同尺寸档（视觉重量一致、垂直居中对齐）——当前偏大。
3. 圆环区域**不出现任何百分比数字/文本**（常驻文本与标签都不得出现）。
4. 语音输入原有行为不受影响：点击/按住说话、快捷键、`aria-label`/可访问名、不可用态（麦克风无权限等）保持原样。
5. 圆环原有行为不受影响：hover/展开的面板（若存在）仍能打开，环形描边粗细与颜色不变（前一批已把已用弧改为 `--ccd-accent` 系）。
6. **新会话页（空会话）同样能看到圆环**，位于状态栏末尾；0 用量时为空心/轨道形态，与有用量时的几何完全一致，且同样不显示百分比。
7. 从空会话切到有内容的会话（以及反向）时，圆环**不跳位、不闪变**，尺寸与位置连续。
8. 浅色 / 深色、以及窗口最窄宽度下：不重叠、不溢出、不换行、不产生横向滚动。
9. `npm run check` 通过。

## 落地提示

- 插件不改宿主组件：优先用**同一条 flex 容器的 `order`**（若状态栏是 flex 且子项顺序可控）或 compat 层 DOM 重排（移动节点 + 打标 + 释放时还原），两种方式都要在注释里写明依据。
- 动手前先在已安装 `app.asar` 与 web 前端产物里核对：状态栏容器类名、语音输入按钮的真实类名/座位、权限选择控件（`wXeViG_`）、上下文圆环（`y0jqnG_`）的 DOM 关系。不要照抄猜测的选择器。
- 宿主 class 哈希只能经 `host-dom.ts` / `host-builds.ts` 访问；新增前缀必须登记，并确认 Windows 构建的别名重写（`aliasHostClasses`）覆盖到。
- 百分比如来自宿主渲染的文本节点或 `aria-label`，优先在 compat 层做**文本/属性级**处理（可释放、可还原），不要用全局文本替换。
- **空会话要显示圆环（本条的难点）**：先在 `app.asar` 里确认宿主在新会话（hero/blank）态是「渲染了但被隐藏」还是「根本没渲染」。前者用收窄作用域的 CSS 显示即可；后者需要插件**自绘一个环**，几何必须与宿主一致：`viewBox="0 0 14 14"`、`cx=cy=7`、`r=5.5`、`stroke-width: 2`、`stroke-linecap: round`、`transform="rotate(-90 7 7)"`，已用弧走 `--ccd-accent` 系 token，轨道走宿主轨道 token。自绘环必须与有用量时**同一位置、同一尺寸**，且切换会话时无跳变。
- 颜色与尺寸变量进 `tokens.css`；业务样式不写字面色值。
- **已确认**：圆环**本体**不显示百分比（宿主有 `.y0jqnG_percent` 文本元素，需要去掉或隐藏）。宿主圆环 hover 时触发器会高亮（`.y0jqnG_trigger:hover,[aria-expanded=true]`）并可能展开明细面板（`.y0jqnG_panel`）——该面板**默认保持原样**，本条不去动面板里的数字；若后续要求面板内也不显示百分比，再单独处理。
