# 已知限制

插件只使用 DSH 的公开接口与样式层，不修改宿主组件。下面这些条目在界面上保留了参考图的外观，但宿主尚未提供对应接口，点击时会说明具体限制，不会伪造状态。

## 会话顶栏

| 条目 | 限制 |
| --- | --- |
| Open repository on GitHub | 宿主不提供仓库信息 |
| Change folder | 会话目录由宿主管理，插件无写入接口 |
| Output style | 宿主未开放输出风格切换 |
| Delete | 宿主未公开删除会话的接口 |

Open in、Rename、Fork、Transcript view、Archive、复制目录路径／名称与打开终端均接入真实操作。目录菜单不显示未提供接口的“在访达中显示”；没有可用终端入口时也不显示“在终端中打开”。

## 浏览器面板

| 条目 | 限制 |
| --- | --- |
| 启动服务器 | 宿主未提供启动入口 |
| 打开本地文件 | 同上 |
| Servers / Files / Settings 三项配置 | 没有对应接口 |
| 独立窗口 | 宿主暂无接口；按钮按需求隐藏 |
| 页面元素选取 | 保留按钮外观，点击说明限制 |
| Save screenshot | 桌面 webview 可用；空页或无接口时禁用 |

## Files 面板

- 全目录搜索未接入：过滤框只检索已加载的行，未展开目录不做服务端搜索。
- 文件树、预览、过滤、树宽拖动、蓝色清单按钮与 ⋯ 菜单均为真实操作。

## 插件市场

插件目录尚未收录，请通过官方插件页或终端安装，见[安装指南](../install.md)。

## 宿主构建

宿主 CSS Module 类名随构建重新哈希。当前登记了 macOS 与 Windows 两套构建；未登记的构建会让界面样式整体失效，插件设置页顶部会给出提示，重新登记的步骤见 [ARCHITECTURE.md](../ARCHITECTURE.md)。
